# DeepLearning Project 2: 이 얼굴을 그리는 z를 찾아라

2026년 2학기 딥러닝기초 **두 번째 프로젝트**입니다.

이미 학습된 얼굴 생성 모델(DCGAN) **G**가 주어집니다.
G는 128개의 숫자 z를 받아 64 × 64 얼굴 하나를 그립니다.

```
z (숫자 128개)  ──>  G  ──>  얼굴 그림 (64 × 64)
```

**실제 얼굴 사진 200장**이 주어집니다. 사진마다 **G가 그 사진과 가장 비슷한 얼굴을 그리게 만드는 z**를 찾아 제출하세요.

G는 학습하지 않습니다. 여러분이 찾는 것은 **G에 넣을 입력 z**입니다.

## 3. 과제

**`z_generator.py`를 고쳐서 점수를 올리세요.** 어떻게 z를 찾을지는 자유입니다.

### 생각해 볼 질문
1. 랜덤으로 더 많이 그려서 고르면 얼마나 좋아질까? 언제부터 더 늘려도 소용이 없을까?
2. 고른 z를 조금씩 바꿔 보면 더 비슷한 얼굴이 나올까?
3. G도 신경망이다. 사진과의 차이를 손실로 두고, **z에 대해** 기울기를 구할 수 있지 않을까?
4. 무엇을 비교해야 "같은 사람"처럼 보일까? 픽셀 차이만으로 충분할까?
5. z가 너무 커지면 어떻게 될까? (G는 학습할 때 **표준정규분포**에서 뽑은 z만 보았다)
6. 아무리 해도 안 맞는 사진은 어떤 사진일까? 왜 G는 그 얼굴을 못 그릴까?

### 규칙

## 4. 채점

서버는 여러분의 z로 `G(z)`를 그려 목표 사진과 비교합니다. 사진 한 장의 점수는 두 가지의 평균입니다.

| 항목 | 의미 | 계산 |
|---|---|---|
| **픽셀 점수** | 색과 형태가 얼마나 같은가 | 픽셀 차이(MSE)를 랜덤 얼굴과 비교 |
| **특징 점수** | 같은 사람처럼 보이는가 | 분류기 특징 벡터의 유사도를 랜덤 얼굴과 비교 |

```
사진 점수 = (픽셀 점수 + 특징 점수) / 2       (0 ~ 1, z가 범위를 크게 벗어나면 0)
최종 점수 = 사진 점수의 평균 × 100           (0 ~ 100점)
```
- 두 점수 모두 **랜덤 얼굴 수준이면 0, 똑같으면 1**이 되도록 맞춘 값입니다.
- 계산 방법은 `score.py`에 그대로 들어 있습니다.

### `score.py`와 서버 점수의 차이
| | `score.py` (내 컴퓨터) | 서버 |
|---|---|---|
| 픽셀 점수 | 같음 | 같음 |
| 특징 점수 | **공개 분류기** | **비공개 분류기** (공개 분류기와 비슷하지만 다름) |
| 사진 | 200장 전체 | public 100장 / private 100장 |

그래서 `score.py`의 점수는 **참고 점수**입니다. 공개 분류기에만 너무 맞춘 z는 서버에서 점수가 덜 나올 수 있습니다.

```
[통과] z 모양 (200, 128)
[통과] NaN / inf 없음
[통과] z 범위: 200개 모두 평균 0, 표준편차 1 근처
------------------------------------------------------------
픽셀 점수 : 0.684
특징 점수 : 0.319  (공개 분류기 기준)
참고 점수 : 50.1 / 100  (서버 점수와 다를 수 있습니다)
가장 안 맞은 사진 10장: [55, 118, 33, ...]  -> worst.png (위: 사진, 아래: 내 결과)
```

### Public / Private
- 사진 200장은 **public 100장**과 **private 100장**으로 나뉘어 있습니다. **어느 사진이 어느 쪽인지는 공개하지 않습니다.**
- 기간 중에는 public 점수만 보이고, 순위도 public 점수로 보여 줍니다.
- 학생마다 **public 점수가 가장 높은 제출 1개**가 최종 제출이 되고, **최종 순위는 그 제출의 private 점수**로 정합니다.
- 그래서 200장 **모두** 잘 찾아야 합니다.
